# Video Frame Sorting

Локальное приложение для восстановления плавного порядка JPEG-кадров. Создаёт план переименования в формате CSV,
применяет его после подтверждения и собирает новый MP4 с временной шкалой и аудио исходного видео.

## Структура проекта

```text
.
├── frame_sorter/          # Анализ кадров, переименование и сборка видео
│   └── web/               # Локальный веб-интерфейс и фоновые задачи
│       └── static/        # Разметка, стили и сценарии браузера
├── resources/             # Ресурсы приложения
│   ├── assets/            # Изображения для документации
│   └── state/             # Состояние и история задач
├── tests/                 # Проверки анализа, файловых операций и видео
├── docs/                  # Дополнительные материалы
├── openspec/              # Требования и документация проекта
│   ├── context/           # Начало работы, архитектура, словарь и решения
│   ├── specs/             # Спецификации и инженерные правила
│   └── changes/           # Открытые изменения и задачи
├── rename_frames.py       # Отдельное применение плана переименования
└── run_web.ps1            # Запуск локального веб-интерфейса
```

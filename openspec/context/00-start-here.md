# Начало работы

1. Обязательно прочитай [инженерную спецификацию](../specs/engineering-governance/spec.md),
   [локальные правила и команды](../specs/engineering-governance/reference/project-specific.md) и
   [границы продукта](../specs/project-context/spec.md).
2. Прочитай [назначение продукта](01-product-context.md). Для задачи по существующему изменению выбери точку продолжения
   в [текущей работе](../changes/README.md); для прямого обслуживания спецификаций действуй в запрошенной области.
3. Выбери предметный контракт: [анализ](../specs/frame-analysis/spec.md),
   [переименование](../specs/rename-transactions/spec.md), [MP4](../specs/video-rebuild/spec.md),
   [локальный веб-интерфейс](../specs/local-web-workflow/spec.md).
4. Остальной контекст читай по вопросу: [словарь](02-domain-glossary.md), [архитектура](03-architecture.md),
   [команды](04-engineering-standards.md), [безопасность](05-security-and-compliance.md),
   [качество](06-testing-and-quality.md), [ошибочные подходы](07-anti-patterns.md),
   [ADR](ADR/README.md), [примеры](examples/README.md).

Полные нормы находятся в спецификациях и их нормативных приложениях. Этот файл задаёт маршрут; тематические указатели,
код и результаты проверок помогают найти и проверить нужную норму.

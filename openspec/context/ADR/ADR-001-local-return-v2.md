# ADR-001: Восстановление локального порядка с сохранением всех кадров

## Статус

Принято.

## Контекст

В последовательности встречаются кратковременные визуальные возвраты. Глобальная похожесть не позволяет отличить их
от естественного повторного появления сцены; удаление похожего изображения меняет состав исходного материала.

## Решение

Восстанавливать локальный порядок по соседним переходам и контексту последовательности. Сохранять каждый исходный кадр
и стабильное соответствие результата исходным позициям. Планирование отделено от изменения имён.
Наблюдаемый контракт принадлежит [анализу кадров](../../specs/frame-analysis/spec.md).

## Альтернативы и последствия

Глобальная перестановка по похожести нарушает естественные возвраты сцены. Удаление повторов теряет кадры; сравнение
только точных хешей не охватывает визуально близкие возвраты. Локальная модель сохраняет состав последовательности,
но не восстанавливает отсутствующие изображения и физически точные моменты съёмки.

## Условия пересмотра

Изменение задачи восстановления: глобальная сортировка, создание отсутствующих кадров либо новая модель временного
соответствия. Настройка порогов существующего детектора не требует отдельного ADR.

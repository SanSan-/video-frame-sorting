# Словарь проекта

| Термин                   | Значение                                                                                     |
|--------------------------|----------------------------------------------------------------------------------------------|
| Возврат                  | Почти повторённый кадр из локального прошлого, создающий два резких соседних перехода        |
| Исходная позиция         | Нулевая позиция после естественной сортировки имён                                           |
| План                     | CSV последовательности и связанные служебные метаданные                                      |
| Биекция                  | Взаимно однозначное соответствие исходных и выходных кадров                                  |
| Группа                   | Транзитивно связанные повторы со стабильным порядком                                         |
| Строгий известный лаг    | Ветка алгоритма локальных возвратов для заранее определённых задержек                        |
| Служебный файл (sidecar) | Метаданные рядом с результатом; текущие метаданные анализа не являются будущим кешем моделей |
| Отмена (undo)            | Обратное переименование, связанное с завершённой транзакцией сортировки                      |
| Кандидат плана           | Найденные артефакты, пригодность которых ещё не подтверждена полной проверкой                |
| VFR                      | Переменная частота кадров                                                                    |
| AAC                      | Формат сжатого аудио, для которого отдельно проверяется сохранность аудиосэмплов             |
| PTS / DTS                | Время показа / декодирования кадра или аудиопакета                                           |
| Копирование аудиопотока  | Перенос сжатых аудиопакетов без повторного кодирования                                       |

# Ошибочные подходы

Указатель помогает найти норму по обнаруженному симптому; полного правила здесь нет.

| Симптом                                                                               | Требование или проверяемый пример                                                   |
|---------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|
| Удаление повторов, глобальная перестановка похожих кадров, принятие неизвестного лага | [ANA-001…003](../specs/frame-analysis/spec.md), [пример 1](examples/README.md)      |
| Изменённый CSV, прямое переименование, удаление материала восстановления              | [REN-002…005](../specs/rename-transactions/spec.md), [пример 2](examples/README.md) |
| Доверие произвольной отмене или состоянию интерфейса                                  | [WEB-004](../specs/local-web-workflow/spec.md), [пример 3](examples/README.md)      |
| Совпало число кадров, но потеряны финальная длительность или аудиоданные              | [VID-003…006](../specs/video-rebuild/spec.md), [пример 4](examples/README.md)       |
| Непроверенная гарантия защиты целевого MP4 от конкурентной перезаписи                 | [VID-007](../specs/video-rebuild/spec.md)                                           |
| Будущие модели объявлены текущей возможностью                                         | [CTX-002](../specs/project-context/spec.md)                                         |

## Purpose

Описывает вход JPEG, детектор локальных возвратов local-return-v2, стабильную биекцию и переносимый CSV-план.

## Requirements

### Requirement: ANA-001 Каталог и естественный порядок

Анализ MUST читать только непосредственные обычные файлы .jpg/.jpeg без учёта регистра, отклонять символьные ссылки на
JPEG и коллизии имён без учёта регистра. Числовые части имён сортируются естественно. Корневой путь нормализуется;
отдельный запрет корневых точек соединения каталогов (junction) не заявляется.

#### Scenario: Произвольные имена

- **WHEN** каталог содержит frame2.jpg и frame10.jpg
- **THEN** frame2 предшествует frame10; при несовместимом общем шаблоне итоговые имена задаются отдельно в метаданных.

Источник: [реализация](../../../frame_sorter/io_utils.py); [проверка](../../../tests/test_io_utils.py).

### Requirement: ANA-002 Локальная близость

Поиск возврата MUST исключать непосредственного соседа и использовать окно 60 кадров. До четырёх кандидатов выбираются
по dHash — хешу различий изображения; визуальное расстояние D определяется средней абсолютной ошибкой (MAE) миниатюр
64×36. Близость D≤3 и расстояние между хешами ≤20 принимается только при двух соседних скачках A и B, каждый из которых
строго больше max(3, 4D).

#### Scenario: Почти статичный участок

- **WHEN** кадры похожи, но оба скачка не превышают порог
- **THEN** одна визуальная близость не делает повтор нарушающим плавность возвратом.

Источник: [реализация](../../../frame_sorter/analysis.py); [параметры](../../../frame_sorter/models.py);
[проверка](../../../tests/test_analysis.py).

### Requirement: ANA-003 Контекст и строгий известный лаг

После проверок ANA-002 возврат MUST иметь плавный обход C<0.75×min(A, B), где C — MAE между кадрами до и после возврата,
либо лаг 7/14 кадров при D≤1.5 и расстоянии между хешами ≤8. Строгая ветка известного лага учитывается отдельно;
неизвестный лаг не обходит проверку контекста.

#### Scenario: Неизвестный лаг 6

- **WHEN** почти точный повтор имеет лаг 6 и неплавный обход
- **THEN** строгая ветка не принимает его.

Источник: [реализация](../../../frame_sorter/analysis.py); [проверка](../../../tests/test_analysis.py).

### Requirement: ANA-004 Стабильная биекция

План MUST объединять транзитивные повторы в группы, стабильно сортировать группы по первому исходному индексу и кадры
внутри группы по исходной позиции. Каждое имя присутствует один раз, итоговые позиции равны 0..N−1.

#### Scenario: Связная цепочка повторов

- **WHEN** несколько повторов образуют одну компоненту
- **THEN** все кадры сохраняются рядом с первым появлением без удаления или дублирования файла.

#### Scenario: Пиксельно одинаковые кадры

- **WHEN** два кадра неразличимы по содержимому
- **THEN** их порядок остаётся стабильным по исходной позиции; время съёмки не выдумывается.

Источник: [реализация](../../../frame_sorter/analysis.py); [проверка](../../../tests/test_analysis.py).

### Requirement: ANA-005 Переносимый план

CSV MUST иметь ровно `position,source_filename` в UTF-8 без BOM; имя файла не содержит пути. Метаданные связывают план
с версией алгоритма, параметрами, итоговыми именами, снимком входов (имя, размер, `mtime_ns`, SHA-256) и SHA-256 самого
CSV. Проверка перед применением определяется [REN-002](../rename-transactions/spec.md#requirement-ren-002-строгая-проверка).

#### Scenario: Создание переносимого плана

- **WHEN** анализ создаёт CSV для проверенной последовательности JPEG
- **THEN** заголовок равен `position,source_filename`, строки содержат имена без путей, а метаданные связывают CSV
  с входным снимком и условиями анализа.

Источник: [реализация](../../../frame_sorter/analysis.py); [проверка](../../../tests/test_renamer.py).

### Requirement: ANA-006 Чтение и отказ

Анализ MUST сохранять содержимое и имена исходных JPEG; повреждённое изображение сообщается как ошибка проверки входов.
Отмена анализа не запускает переименование. Блокировка при незавершённой транзакции определяется
[REN-004](../rename-transactions/spec.md#requirement-ren-004-отказ-и-восстановление).

#### Scenario: Повреждённый JPEG

- **WHEN** декодирование одного входа завершилось ошибкой
- **THEN** операция завершается понятной ошибкой проверки без изменения оригиналов.

Источник: [реализация](../../../frame_sorter/analysis.py); [проверка](../../../tests/test_analysis.py).

## Purpose

Определяет конкретные ограничения среды, текстовых файлов, сохранности пользовательских данных и инженерной проверки
локального сортировщика. Команды и параметры находятся в [нормативном приложении](reference/project-specific.md).

## Requirements

### Requirement: ENG-001 Среда и рабочие входы

Рабочая среда и зависимости MUST соответствовать [конфигурациям и командам проекта](reference/project-specific.md#среда-и-зависимости).
CLI, локальный веб-интерфейс и дополнительный вход переименования SHALL использовать предусмотренные там рабочие входы
и предметные контракты.

#### Scenario: Подготовка среды

- **WHEN** подготавливается установка для анализа, переименования или пересборки видео
- **THEN** используются установленная конфигурацией версия Python, закреплённые зависимости и указанные в приложении
  внешние средства; операции запускаются из корня проекта.

### Requirement: ENG-002 Кодировка и совместимость сценариев

Текстовые файлы проекта MUST сохраняться в UTF-8 без BOM; комментарии, журналы приложения и строки документации Python
SHALL быть по-русски. Сценарии запуска приложения на PowerShell MUST сохранять ASCII для Windows PowerShell 5.1, как определено в
[правиле совместимости](reference/project-specific.md#язык-и-совместимость-скриптов).

#### Scenario: Подготовка сценария PowerShell

- **WHEN** изменяется сценарий запуска приложения на PowerShell для Windows PowerShell 5.1
- **THEN** его текст остаётся ASCII и не зависит от распознавания UTF-8 без BOM этой оболочкой.

### Requirement: ENG-003 Сохранность данных при проверках

Проверки MUST сохранять исходные JPEG, оригинальный MP4, существующие результаты и материалы восстановления.
Проверки с изменением имён или файлов SHALL выполняться на отдельных копиях по
[правилам проверки проекта](reference/project-specific.md#проверки). Защиту при предметной операции определяют ANA, REN и VID.

#### Scenario: Сквозная проверка переименования и пересборки

- **WHEN** проверка включает применение плана, восстановление либо создание MP4
- **THEN** она использует отдельную копию входных данных и новый путь результата; пользовательские оригиналы,
  существующие результаты и материалы восстановления сохраняются.

### Requirement: ENG-004 Обязательные проверки

Изменение поведения MUST проходить [обязательные проверки проекта](reference/project-specific.md#проверки).

#### Scenario: Проверка изменённого кода

- **WHEN** изменён код проекта
- **THEN** предусмотренный набор проверок из локального приложения завершается успешно.
